## CSE Graduate Studies Reference Notes

A personal repository dedicated to organizing academic notes, coursework implementations, and technical documentation from my Master's studies in Computer and Systems Engineering (CSE).

## Core Focus Areas

1. Advanced Software Engineering
     - Design Patterns & Architecture: Structural breakdowns and implementations of core software engineering design paradigms.
     - System Verification: Methodologies for testing, debugging pipelines, and software quality assurance.
     - DevOps Practices: Automation, continuous integration, and infrastructure workflows.

2. Advanced Computer Architectures
     - Processor Design: Analysis of modern CPU architectures, pipelining, and execution strategies.
     - Memory Subsystems: Exploration of cache coherence protocols, latency optimization, and memory hierarchies.
     - Parallel Computing: Concurrency, synchronization primitives, and distributed computing models.
     - Quantum Computing: Notes on foundational quantum mechanics applied to computing and qubit state logic.
